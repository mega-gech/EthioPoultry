# HenEthio – Ethiopian Poultry & Egg Marketplace

HenEthio is a web-based marketplace designed to connect poultry farmers, egg sellers, buyers, and agricultural service providers across Ethiopia.

The platform aims to make it easier for users to discover poultry products, compare prices, find local sellers, and connect directly with suppliers.

## Features

* 🥚 Browse eggs and poultry products
* 🐔 Discover hens and other poultry products
* 🔍 Search and explore product listings
* 📍 Find sellers by location
* 📱 Responsive design for desktop and mobile devices
* 🤝 Connect buyers with local farmers and suppliers

## Getting Started

### Prerequisites

* Node.js and npm
* Git
* A code editor such as Visual Studio Code

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/mega-gech/HenEthio.git
   ```

2. Navigate to the project folder:

   ```bash
   cd HenEthio
   ```

3. Navigate to the frontend:

   ```bash
   cd client
   ```

4. Install dependencies:

   ```bash
   npm install
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL shown in your terminal, usually `http://localhost:5173`.
